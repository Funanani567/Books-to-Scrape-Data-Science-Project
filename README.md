Project Overview
This project involves collecting book data from the Books to Scrape website through web scraping. The data is then cleaned, analysed, visualised, and used to build a Linear Regression model for predicting book prices.

Objectives
Collect book data using web scraping.
Clean and prepare the dataset.
Perform exploratory data analysis.
Create data visualisations.
Build a Linear Regression model.
Evaluate model performance.

Findings
